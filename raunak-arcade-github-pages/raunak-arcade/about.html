BEHIND THE PIXELS

A SMALL LAB.
BIG IDEAS.

Raunak Arcade is a personal browser-game project: a place to build, test and improve games while learning how code becomes something you can play.

01 / THE MISSION

Learn by making.

Every game is a new experiment in logic, movement, design and problem-solving. The goal is to keep building and make each version better than the last.

02 / BUILT FOR THE WEB

Click. Load. Play.

The site uses HTML, CSS and JavaScript, so the games run in a modern browser. GitHub Pages can host the files for free without a separate server.

03 / NEXT LEVEL

Always evolving.

Add new games, improve controls, tune difficulty and bring new ideas to the arcade. This is a starter project you can keep customizing.
