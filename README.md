# Raunak Arcade — GitHub Pages starter

A responsive static gaming website with a home page, game gallery, about page, animations, and four browser games.

## Files
- `index.html` — homepage
- `games.html` — game gallery with category filters
- `about.html` — project information
- `games/` — individual game pages
- `assets/` — shared styling and game scripts

## Publish with GitHub Pages
1. Sign in to GitHub and create a **Public** repository, e.g. `raunak-arcade`.
2. Extract this ZIP on your computer.
3. Upload the **contents inside** the `raunak-arcade` folder to the repository root. `index.html` must be visible on the repository's main page; do not upload only the ZIP.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/(root)`, then click **Save**.
7. Wait a few minutes and open `https://YOUR-USERNAME.github.io/raunak-arcade/`.

## Customize
- Change the title/brand text in each HTML file if you want a different site name.
- Add a new card to `games.html` and `index.html` for another game.
- Add more games as separate files in `games/`.
- All games run in the browser; no backend server is required.

## Notes
- Google Fonts are loaded from the web; if unavailable, the site falls back to system fonts.
- GitHub Pages is public hosting. Do not add private information, API keys, or passwords.


New games: **Snake** (keyboard and touch controls) and **Chess** (two-player pass-and-play, responsive board). Both are designed for mobile and laptop browsers.


Additional games added: Neon Runner, Space Invaders, Brick Breaker, Tower Defense, Minesweeper, and Tic-Tac-Toe. Designed for mobile touch and laptop controls.
